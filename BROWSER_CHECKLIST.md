# Чек-лист ручной проверки в браузерах

Автоматически проект проверялся только в Chromium. Пройдите этот список в каждом браузере:

- Safari на iPhone;
- Safari на Mac;
- Firefox на компьютере;
- Chrome на Android.

Займёт около 10 минут на браузер.

**Подготовка.** Откройте сайт: `npm run dev` или опубликованный адрес. Перед началом нажмите «Настройки → Сбросить демо-данные».

Отмечайте: ✅ работает, ❌ не работает (запишите, что видите).

## 3. Клавиатура (только на компьютере)

| # | Действие | Ожидаемый результат | Safari Mac | Firefox |
|---|---|---|---|---|
| 3.1 | Открыть «Добавить операцию» и нажимать Tab | Фокус ходит по кругу внутри окна | | |
| 3.2 | Нажать Esc | Окно закрывается, фокус возвращается на кнопку «Добавить операцию» | | |

В Safari на Mac Tab по умолчанию переходит только по полям. Чтобы он ходил и по кнопкам, включите в настройках Safari «Дополнения → Нажатие клавиши Tab выделяет каждый объект на веб-странице».

## 4. Системные настройки

| # | Действие | Ожидаемый результат |
|---|---|---|
| 4.1 | Включить «Уменьшить движение» (iOS: Универсальный доступ → Движение; macOS: Универсальный доступ → Монитор) и перезагрузить сайт | Блоки и экраны появляются без сдвигов, только плавным проявлением |
| 4.2 | Открыть сайт в приватном режиме Safari | Сайт работает; после перезагрузки данные могут сброситься — это нормально |
